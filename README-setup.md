# Шёпот — статический чат (index.html)

Один HTML-файл. Никакого сервера запускать не нужно — просто загружаете файл на любой хостинг. Для синхронизации сообщений между разными людьми используется бесплатная база данных Firebase (Google) — её тоже не нужно программировать, только один раз создать через веб-интерфейс.

## Шаг 1. Создать бесплатный проект Firebase (5 минут)

1. Откройте https://console.firebase.google.com и войдите под любым Google-аккаунтом
2. «Add project» → введите любое имя → создайте проект (Google Analytics можно отключить, не нужен)
3. В левом меню: **Build → Realtime Database → Create Database**
   - Выберите любой регион
   - Режим запуска: **test mode** (потом ужесточим правила — см. шаг 3)
4. В левом меню: **Build → Authentication → Get started** → вкладка Sign-in method → включите **Anonymous**
5. Значок шестерёнки → **Project settings** → внизу «Your apps» → нажмите `</>` (Web app) → зарегистрируйте (имя любое) → скопируется блок `firebaseConfig`

## Шаг 2. Вставить ключи в файл

Откройте `index.html` в любом текстовом редакторе (Блокнот подойдёт), найдите в самом начале блок:

```js
const FIREBASE_CONFIG = {
  apiKey: "ВСТАВЬТЕ_СЮДА",
  authDomain: "ВСТАВЬТЕ_СЮДА.firebaseapp.com",
  databaseURL: "https://ВСТАВЬТЕ_СЮДА-default-rtdb.firebaseio.com",
  projectId: "ВСТАВЬТЕ_СЮДА",
  appId: "ВСТАВЬТЕ_СЮДА"
};
```

и замените значения на те, что скопировались на шаге 1.5. Сохраните файл.

## Шаг 3. Ограничить доступ к базе (важно!)

По умолчанию «test mode» открыт вообще всем в интернете на 30 дней. Чтобы писать в вашу комнату могли только те, у кого есть ссылка на ваш сайт (а не боты, сканирующие Firebase), в консоли: **Realtime Database → Rules** — вставьте:

```json
{
  "rules": {
    "rooms": {
      "$room": {
        ".read": "auth != null",
        ".write": "auth != null"
      }
    }
  }
}
```

и нажмите **Publish**. Это разрешает читать/писать только тем, кто анонимно авторизовался через ваш сайт (это происходит автоматически, никакого пароля вводить не нужно) — обычные боты и прямые запросы к базе так не смогут.

## Шаг 4. Разместить на хостинге

Файл `index.html` статический — подходит любой хостинг для статики:

- **Netlify / Vercel**: перетащить файл в интерфейс загрузки — сайт готов за секунды
- **GitHub Pages**: закинуть файл в репозиторий, включить Pages в настройках репозитория
- **Обычный хостинг** (Timeweb, Beget и т.п.): загрузить файл по FTP в корень сайта

После этого откройте свой сайт, нажмите «Создать комнату» — в адресной строке появится `ваш-сайт.ру/#/r/код`. Эту ссылку и отправляйте друзьям.

## Что важно понимать

- **Это не end-to-end шифрование.** Сообщения, голосовые и кружки хранятся в вашей базе Firebase в читаемом виде — их может увидеть тот, у кого есть доступ к вашему проекту Firebase
- **Комната открыта всем, у кого есть ссылка** — доступа по паролю нет (можно добавить, если понадобится)
- Голосовые и кружки хранятся как base64 прямо в базе данных, поэтому запись **ограничена по времени** (30 сек для голосовых, 12 сек для кружков) — иначе бесплатный лимит Firebase (1 ГБ хранилища, ~360 МБ трафика в день) быстро закончится. Эти лимиты можно поменять в файле — ищите `MAX_SECONDS`
- Бесплатного тарифа Firebase (Spark) с запасом хватает на переписку с друзьями каждый день

## Если что-то не работает

- Сообщения не приходят → проверьте, что в шаге 1.4 включили Anonymous-авторизацию, и что ключи в шаге 2 скопированы без опечаток
- «Permission denied» в консоли браузера (F12) → проверьте правила из шага 3
- Не работает запись голосового/видео → браузер должен быть открыт по **https** (обычный http не даёт доступ к микрофону/камере); все указанные выше хостинги дают https автоматически
